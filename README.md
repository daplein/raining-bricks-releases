# It's Raining Bricks

An ad-free falling-blocks game for Android. Bricks rain down from the night
sky: swipe to move, tap to spin, flick down to drop, flick up to hold, and
build them into lines. Four lines at once? **Hallelujah!** With cheats, if
you're into that, and a leaderboard to share with friends.

**[Install It's Raining Bricks](https://daplein.github.io/apps/raining-bricks/)**:
open that page on your Android phone and tap *Download for Android*. Or scan
this with the phone's camera:

<img src="https://daplein.github.io/apps/raining-bricks/qr.svg" alt="QR code for the install page" width="180">

To share it from the game, tap **Share** on the start screen: a friend scans
the code, or tap **Send link** to send it in a chat. The game also tells you
when a new version is out.

## Install on Android (13 or newer)

1. On the phone, open the [install page](https://daplein.github.io/apps/raining-bricks/)
   and tap **Download for Android**.
2. When Chrome asks **File might be harmful**, tap **Download anyway**
   (it asks that for every app that isn't from the Play Store).
3. Tap **Open**. If Android asks, allow Chrome to **install unknown apps**.
4. Tap **Install**, then open **Raining Bricks**.

New versions install over the old one; your settings and best score stay.

All versions: [Releases](https://github.com/daplein/raining-bricks-releases/releases).
